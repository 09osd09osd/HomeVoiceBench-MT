# 本地人工听音评审台

双击 `启动人工评审.cmd`，浏览器打开 `http://127.0.0.1:18789/review/`。页面读取 `review/data.json`，不调用模型。

## 能做什么

- 左侧筛选 200 个案例（场景/话题/编号）；
- 逐检查点查看：用户话术、期望工具/探针、五个系统的逐维分数、**判官理由**、违规项、样例音频；
- 顶部客观指标：工具正确/应有、参数 F1、漏调/乱调、探针命中；
- 写人工备注（本地存储），导出评审 JSON/CSV。

## 音频说明

Git 仓库含 2 段样例（`assets/sample/`）；完整 200 段音频体积大，需按 [DELIVERY.md](DELIVERY.md) 放置到本机，否则页面显示“无样例音频”。
