# 场景与配额

## 家居（home）

话题：做饭饮食、家居设备、出行安排、家庭健康、收纳整理、家务清洁、家庭财务。
工具：add_note(title, content)、set_reminder(content, time_text)、query_items(kind, keyword)。
轮次设计：distract / change / resume / tool / pure_chat。

## 儿童（child）

话题：睡前故事、动物朋友、校园生活、情绪安抚、好奇心问答、游戏想象、家庭日常、节日生日、安全常识。
年龄段：7–8 岁、8–10 岁。

两个场景各 1,000 段，评测各取前 100 段；每段固定 10 轮。
